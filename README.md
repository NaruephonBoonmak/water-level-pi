## วิธีใช้
- ปุ่ม ‹ › ด้านล่าง หรือปุ่มลูกศร ← → / Space · คลิกบนสไลด์ = ถัดไป
- ⛶ หรือกด F = เต็มจอ · N = บันทึกผู้บรรยาย · Ctrl+P = พิมพ์/PDF
- หน้า V-Model (6) เปิดทีละขั้น · หน้าวิดีโอ (33) กด ▶ เพื่อเล่น และหยุดเองเมื่อเปลี่ยนสไลด์
